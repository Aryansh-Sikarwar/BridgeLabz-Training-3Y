BridgeLabz Training – GitHub Repository
Structure Guidelines

Purpose
This document defines the standard GitHub repository structure that all learners should follow
while submitting practice programs, assignments, and coding exercises during training.
Maintaining a consistent structure helps mentors review code efficiently and ensures better
project organization.
